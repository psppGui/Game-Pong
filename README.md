# Game-Pong

Jogo do Pong feito em Java usando AWT/Swing, com alguns ajustes de jogabilidade para deixar a experiência mais polida.

## Como executar

```bash
javac src/PongGame.java
java -cp src PongGame
```

## Controles

- `W` / `S`: mover a raquete da esquerda
- `P`: pausar/continuar
- `R`: reiniciar partida

## Ajustes aplicados

- Placar até 10 pontos
- IA simples para a raquete adversária
- Aumento gradual de velocidade da bola
- Mensagens de pausa e vitória na tela
